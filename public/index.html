Powered by a handshake CLI

MotionDex doesn't guess its index — it asks each site for its catalog, politely. When a site refuses the polite handshake, the CLI falls back to scraping, then to the last successful snapshot. It always comes home with data.

🤝 api

Animista ships its whole catalog as animista.json — 662 variations with default timing.

📄 raw-css

Animate.css class names are parsed straight from animate.min.css on GitHub.

🕸 scrape

Loading.io & Uiverse get fetched with browser headers; if the bot-wall says no, the CLI retries through curl.

🌱 seeds

Every successful handshake is snapshotted to cli/seeds/, so --offline always has fresh-ish data.
